## GitHub 云端部署

已配置 GitHub Actions：推送 `main` 分支后，检查通过即将 `dist/` 发布到 GitHub Pages。首次使用需在仓库 Settings → Pages 将 Source 设为 GitHub Actions。完整步骤和学习记录迁移方法见 [GITHUB-PAGES.md](GITHUB-PAGES.md)。

中文零基础到 N2 的自学流程：N5 → N4 → N3 → N2，各等级都有语法课程、词汇卡、阅读、合成语音听力、专项练习、错题本及 20 题阶段测评。

N5 系统课程：24 个场景单元、72 个语法讲解（每节两组日语/假名/中文例句）、24 篇阅读和24 段合成语音听力（各三道理解题）、612 张去重词卡、109 个基础汉字、8 节发音说明。每单元20个词，词汇分两组、语法、阅读、听力、10题复习共六步，前五步完成且复习达到80%后记录通过。四次20题阶段复习和40题结课测评单独保存；可选写作草稿按单元保存。保留原入门课和所有原ID，N4 已增加系统单元（见下），N3 已增加系统单元（见下），N2 也已增加系统单元（见下）。课程是原创教学选编，部分后期句型注明N4衔接；不是官方固定考试词表或语法表。

课程讲解与随堂题；词汇 1/3/7/14/30/60 天间隔复习，同一天重复确认不提升复习盒；阅读/听力含原文、翻译、题目、解析；完整阶段测评保存分项成绩，未完成测评不写入成绩历史。刷新后可继续练习。每日计划支持起点、目标、20/40/60 分钟预算。

`dist/base-data.js` 保留原入门课；`dist/curriculum.js` 保存新增分级内容；`dist/journey.js` 是应用逻辑。`dist/index.html` 是入口。`node verify-journey.cjs` 运行内容、迁移、测评及持久化检查。

运行：`node server.cjs`，打开 http://127.0.0.1:4173 。网页源文件在 `dist/`，无需安装依赖。

发音与听力使用浏览器 Web Speech API，需要系统提供日语语音；合成语音不替代真人听力材料。新版进度存入 `hajime-study-v2`，自动读取旧版 `hajime-study-v1` 进行迁移，旧记录保留。支持 JSON 导出与校验后导入合并；登录同一账号后自动跨设备同步；首次登录可导入本机原有进度，详见 [CLOUD-SYNC.md](CLOUD-SYNC.md)。备考仍需扩大词汇与汉字、更多题型与篇章，并配合官方材料。本站测评正确率不换算 JLPT 分数。

视觉参考暨南大学官网的校院式导航、深蓝配色和横幅布局；未使用学校标志。风景插画为本项目原创 SVG。
# 独立真题训练

这是历次真题精选集，不标注为某次考试原卷。官方题目 PDF 和音频在新标签打开；
本站提供按科目/题型的答题卡，以及整卷计时、标记、笔记、核对和记录备份。
不嵌入或托管官方题文、音频。数值答案索引在 `dist/real-data.js`；来源：
https://www.jlpt.jp/e/samples/sampleindex.html

`.package/official-reference/{2012|2018}-{N5|N4|N3|N2}.txt`，再运行工具。
该目录仅为本地验证缓存，不随网站发布。运行 `node verify-journey.cjs` 验证题库、
评分、保存恢复、导入校验，以及与每日计划的隔离。


# N5 内容维护

`n5-units-a.json` / `n5-units-b.json` 是24单元原创内容，`n5-reference.json` 是词汇、汉字、发音选编。运行 `node build-n5.cjs` 校验并生成 `dist/n5-data.js`；`n5-data-adapter.js` 为稳定ID与旧词卡去重接入。
`dist/n5.js` / `dist/n5.css` 实现单元课程、汉字、分段和结课测评，并接入每日计划及 `hajime-study-v2` 的 `course` 字段。
每日20/40/60分钟安排1/2/3个单元步骤，另加至多5个到期旧词；未完成保留，完成可手动推进。旧N5每日任务升级为单元任务，旧课程记录与旧写作草稿保留。
`node verify-n5.cjs` 验证144个单元步骤页面、顺序/通过门槛、每日计划、复习续答和导入校验；`node verify-journey.cjs` 验证四级原有流程和独立真题不受影响。

语音稳定性：`dist/audio.js` 保留合成语音对象、优先本地日语声音、同句重复点击不打断、长文本分句排队，并区分主动停止与真实合成错误。顶部「语音设置」可选择声音、试听和查看诊断。声音选择存于 `hajime-audio-v1`；不修改系统声音设置。`node verify-audio.cjs` 检查取消、重入、分句和错误分支。

## N4 系统课程与收藏（2026-10-28）

`dist/n4-data.js` 为原创教学选编：24 个主题单元、48 个句型讲解与练习、144 条单元词汇条目（复用相同词条）、24 篇阅读、24 段合成语音对话。每单元按词汇、句型、阅读、听力、复习推进，复习先完成前四步并达到80%；结课48题。覆盖普通体、解释、可能、准备、条件、授受、推测、被动、使役和敬语等。不是官方固定考纲或完整考试词汇表，仍需扩大词汇并搭配官方真人音频。

`dist/n4.js` 接入每日计划、逐题答案、写作草稿和结课续答；`dist/favorites.js` 支持跨等级收藏单词、句型、例句，分类搜索与回忆模式。新增记录位于原 study 文档的 n4 / favorites 字段，复用既有云端权限和版本冲突保护，JSON导入合并、导出保留。

`node verify-n4.cjs` 检查内容、120个步骤页面、题型、通过门槛、收藏校验、导入与刷新恢复。内容维护时保持单元、题目和例句ID稳定，不直接更改旧ID。能力目标参考 [JLPT 官方说明](https://www.jlpt.jp/e/about/levelsummary.html)。

### N4 内容扩充（2026-10-28）

`dist/n4-more.js` 在原ID之上追加内容：每单元12条词汇、每句型2组例句、阅读与听力每篇3题，单元复习8题（至少7题正确）。另有8节补充语法（各2组例句），以及条件、授受与礼貌、被动使役敬语、新增语法的专项练习入口。新增单词、例句沿用收藏机制；复习题、专项练习和写作草稿沿用 study 云端文档。

旧例句索引、原题ID、结课测评的48个题目ID保持稳定；旧已完成步骤不撤销。新学习者按扩充后的题目完成步骤，已完成课程的学习者可自由补做。阅读、听力目录按篇章组织，避免一篇重复出现三次。维护时先加载 n4-data.js，再加载 n4-more.js，最后加载 study-extras.js 和应用逻辑。


## N3 系统课程（2026-11-02）

`dist/n3-data.js` 增加原创教学选编：24 单元，四个模块（行动与时间、原因与条件、判断与建议、表达与沟通），48 节句型讲解与练习、96 组日语/假名/中文例句、240 条单元词汇条目（跨单元复现，去重后 230 个课程词条）、24 篇阅读和 24 段合成语音对话，每篇三题，共 144 道篇章理解题。前几单元包含 N4 衔接复习；不是官方固定考纲、完整考试词表或官方真题。能力目标参照 [JLPT 官方说明](https://www.jlpt.jp/e/about/levelsummary.html)。

`dist/n3.js` 提供五步学习路线（词汇→句型→阅读→听力→单元复习）、四组各 12 题模块专项练习、48 题结课测评、20/40/60 分钟每日安排和手动下一学习日。单元复习沿用本单元八题，前四步完成且至少答对七题才通过；结课测评独立作答，交卷前可改选、交卷后统一解析，并进入测评记录。可选写作草稿、单词/句型/例句收藏共用学习档案；自评单词不重建卡片，保留展开状态，沿用现有读音自动播放与复习间隔。

`study-extras.js` 清洗与合并 n4 / n3 / favorites，N3 学习日、单元作答、草稿和测评保存在同一 study 文档；cloud-sync 的空记录判断和导入回执识别 N3，沿用现有登录、账号隔离与版本冲突保护。没有更改数据库、权限或登录配置。保持旧 N3、N5、N4 ID，原 N3 训练篇章在读听目录的折叠区保留。

两个入口的加载顺序为：基础数据 → N5 数据 → N4 数据/扩充 → N3 数据 → study-extras → 主应用 → N5/首页/N4/N3 逻辑 → 收藏 → 云同步。新增文件或修改数据时需递增入口资源版本，保持 ID 和例句索引稳定。`node verify-n3.cjs` 覆盖 120 个步骤页、各等级页面、整单元点击流程、答错重做、每日门槛、收藏草稿导入/恢复、结课续答和提交、专题练习恢复、N3-only 云端保存/导入与旧记录兼容。


## N2 系统课程（2026-11-03）

`dist/n2-data.js` 为原创进阶教学选编：24 单元、48 节句型讲解与随堂练习、96 组日语/假名/中文例句、288 条单元词汇条目（跨单元复现，去重后 244 个课程词条）、24 篇阅读和 24 段合成语音对话。每篇四题，日文题干、日文四选一选项、中文解析，共 192 道篇章理解题。四模块依次为时间过程、对比条件、判断责任、范围立场；加入主旨、条件、依据、意图、下一行动和表述辨析。并非官方固定考纲、完整考试词表或真题；部分表达兼作进阶复习，仍需扩充词汇、长篇阅读和官方真人听力。能力目标参照 [JLPT 官方能力说明](https://www.jlpt.jp/sp/tw/about/levelsummary.html)。

`dist/n2.js` 沿用五步路线：词汇→句型→阅读→听力→单元复习。单元复习使用本单元的两道语法和八道篇章题，共十题，前四步完成且至少答对八题后通过。四组模块专项练习各十二题；独立四十八题结课测评可续答、改选，交卷后统一解析并写入测评记录，重复点击不会重复记分。每日安排按 20/40/60 分钟分配一至三步，未完成保留，完成后可手动开始下一学习日。

单词展开自动发音、自评时保留展开状态；句型/例句/单词可收藏并集中复习。每单元可选观点写作保存草稿，提供参考与自查，不自动评分。新记录放在原 study 文档的 n2 字段，清洗、JSON 合并、导出、账号缓存和云端版本保护沿用现有机制；空记录识别和导入回执均包含 N2。未更改数据库或权限，原 N5/N4/N3 和旧 N2 示例 ID 保留，旧 N2 篇章在目录折叠区继续可用。

两个 HTML 入口先加载 n2-data.js，再加载 study-extras.js；n2.js 在 n3.js 后、收藏和云同步前加载，缓存版本为 20261103。`node verify-n2.cjs` 检查内容形状、四选一答案分布、双角色对话拆分、入口依赖、120 个步骤页、十题门槛、真实点击完成流程、旧等级兼容、每日推进、收藏草稿及结课测评的恢复/合并，以及仅有 N2 记录的云端保存和导入。维护时保持单元、题目、词条和例句索引稳定。


## N5–N2 路线与补充训练（2026-11-03）

新增 `dist/course-plus-data.js` / `course-plus.js` / `course-plus.css`。顶部「学习路线」按等级呈现 24 个单元，每六单元连接一组全新阶段练习，分开显示单元通过、补充课已学、阶段最佳成绩和结课成绩。建议完成该级单元且结课达到 80% 后进阶，但不以本站门槛冒充 JLPT 合格标准。

每级八节辨析课，共三十二节、六十四组日语/假名/中文例句。N5 重点为助词、数量时间、范围、邀请和频率；N4 补希望请求、方法、状态与准备、样态例外、建议、正要动作和长句修饰；N3 补消息来源、预期标准、瞬间时序、程度与许可、承认后保留；N2 补发现结果、相称评价、线索推断、非简单判断、假设、正式转折及强烈情感。部分内容用于巩固和衔接，不标为三十二个全新的官方考点。例句和句型均可收藏。
